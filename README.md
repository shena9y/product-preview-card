# Product Preview Card Component

A solution to the **Frontend Mentor** "Product preview card component" challenge, built with HTML & CSS. The card showcases the *Gabrielle Essence Eau de Parfum* product with a side-by-side image/details layout, a strikethrough original price and an "Add to Cart" button — centered on a soft cream background.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Frontend Mentor](https://img.shields.io/badge/Frontend%20Mentor-3F54A3?style=for-the-badge&logo=frontendmentor&logoColor=white)

## ✨ Features

- 🛍️ Two-column card: product image + details panel
- 🏷️ Category eyebrow text ("Perfume"), title and description
- 💲 Price block with current price (`$149.99`) and strikethrough original (`$169.99`)
- 🛒 "Add to Cart" button with cart icon
- 🎨 Design-token colors via CSS custom properties (Dark cyan, Cream, …)
- 🔤 Fraunces & Montserrat Google Fonts per the challenge design
- 📐 Flexbox centering on a full-height cream background

## 🛠️ Tech Stack

- **HTML5** — card markup
- **CSS3** — Flexbox, custom properties & normalize.css
- **Google Fonts — Fraunces / Montserrat** — typography

## 📂 Project Structure

```
├── index.htm           # Product card markup
├── CSS/
│   ├── style.css       # Card layout & theme
│   └── normalize.css   # CSS reset
└── images/             # Product images, cart icon & favicon
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shena9y/product-preview-card.git
   ```
2. Open `index.htm` in your browser — no build step required.
